# Гомий XII–XIII вв. — интерактивная реконструкция

Статический вьюер (three.js) реконструкции древнего Гомеля: рельеф FABDEM, план «Гомель в XII–XIII вв.» О. А. Макушникова как геометрическая основа, план местечка Гомля XVIII в. для островов и берега.

Сайт: https://gomiy.upupa.dev

Файлы собираются из рабочего проекта (`gomiy-reconstruction/city/web`); `gomiy.glb` сжат meshopt (`@gltf-transform/cli meshopt`), вьюер подключает `MeshoptDecoder`.
